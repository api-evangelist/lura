# Lura Project (lura)

Lura Project (formerly the KrakenD framework) is an open-source, ultra-performant API gateway framework for building custom API gateways with middleware and plugin support. It is hosted under the Linux Foundation and provides a stateless library for aggregating multiple backend microservice responses into single endpoints, supporting HTTP/HTTPS, response transformation, filtering, and Go-based plugin extensibility.
